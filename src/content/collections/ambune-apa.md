## Konteks

Judul daftar ini sekaligus pertanyaannya: *ambune apa?* — baunya apa? Jawabannya punya kata sendiri di bahasa Jawa, dan penting untuk hidup bersama ternak serta sawah: membedakan bau yang wajar dan yang menandakan busuk.

| Jawa | Indonesia | Catatan |
| --- | --- | --- |
| ambu | bau — bauan | kata dasar |
| wangi | harum | |
| arum | harum | |
| busuk | busuk | |
| amis | bau amis — bau ikan/daging | |
| nyengat | menyengat — bau menusuk | |
| ambu rakik | bau keringat | rakik = keringat |
