## Konteks

*Pentil* adalah kuncup — kembang yang belum mekar. Bahasa Jawa punya kata terpisah untuk setiap tahap hidupnya, dari bakal kembang sampai gugur; perhatian sekecil ini juga yang membuat uraian kembang dalam tembang terasa hidup.

| Jawa | Indonesia | Catatan |
| --- | --- | --- |
| pentil | kuncup bunga | |
| bakal | bakal kembang — calon kembang yang baru muncul | |
| megar | mekar | |
| layu | layu | |
| gugur | gugur — jatuh dari tangkainya | |

> Catatan penyusunan: daftar pendek dan ditarik dari makna kata pada rujukan; urutan tahap serta istilah tambahan (mis. *wayah*) perlu dicek silang dengan sumber cetak sebelum dipublikasikan.
