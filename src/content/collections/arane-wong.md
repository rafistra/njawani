## Konteks

Tahap hidup manusia dalam bahasa Jawa tidak dibagi kasar menjadi bayi-anak-dewasa-tua: setiap tahap punya namanya sendiri, sering berdasarkan perkembangan yang ditandai anak itu — baru bisa merangkak, mulai ngobrol, atau sudah tahu malu.

| Jawa | Indonesia | Catatan |
| --- | --- | --- |
| jabang bayi | bayi | |
| cenil | anak yang baru bisa merangkak dan jatuh-bangun | |
| kucel | anak yang mulai aktif bergerak bebas | |
| ndablek | anak yang mulai bisa bercakap-cakap | |
| mandhep | anak yang sudah mengerti — mulai tahu malu | |
| truna | pemuda | |
| truni | gadis remaja | |
| sepuh | orang tua — yang telah tua | ragam halus |
| dhetes | perempuan yang telah bercerai atau ditinggal suami | |

Untuk sebutan khusus anak-anak, lihat [[sebutane-bocah]].

> Catatan penyusunan: daftar menunggu pemeriksaan editorial; sebutan tahap dewasa dan tua akan dilengkapi dari sumber cetak.
