## Konteks

*Rasane apa?* — rasanya apa? Dapur Jawa mengenal rasa dengan kata yang juga jadi sumber sanepa: *legi bratawali* justru berarti pahit sekali (lihat [[sanepa]]).

| Jawa | Indonesia | Catatan |
| --- | --- | --- |
| legi | manis | |
| amis | manis — rasa manis | dipakai di sebagian wilayah |
| pait | pahit | |
| kecut | asam | |
| asem | asam | |
| asin | asin | |
| pedhes | pedas | |
| sepet | kelat — sepet | |
| gurih | gurih | |
