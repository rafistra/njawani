## Konteks

Orang Jawa menandai tumbuh kembang anak dengan tahapan yang rinci. Kata-kata ini bukan julukan, melainkan sebutan baku untuk usia dan perilaku anak — dan sering dipakai orang tua dengan bangga: *"bocahku wis mandhep."*

| Jawa | Indonesia | Catatan |
| --- | --- | --- |
| cenil | anak yang baru bisa merangkak dan jatuh-bangun | |
| kucel | anak yang aktif — mulai bebas bergerak ke mana-mana | |
| ndablek | anak yang mulai lancar bercakap-cakap | |
| mandhep | anak yang sudah paham — mulai tahu malu | |
| sapih | anak yang sudah disapih | |
| yatim | anak yang ditinggal wafat ayahnya | |
| piatu | anak yang ditinggal wafat ibunya | |
| welasan | anak angkat | |

Bagian dari kata-kata ini juga muncul pada [[arane-wong]] karena keduanya menandai tahap usia.
