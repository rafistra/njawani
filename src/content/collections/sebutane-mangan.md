## Konteks

Dalam bahasa Jawa, *mangan* (makan) punya banyak padanan sesuai siapa yang makannya — bukan karena unggah-ungguh, melainkan karena cara makannya berbeda: kebo memakan rumput dengan cara yang tidak sama dengan pitik mematuk beras. Itulah sebabnya daftar ini pasangan kata, bukan sinonim bebas.

| Kewan | Sebutan mangane | Indonesia | Catatan |
| --- | --- | --- | --- |
| pitik | meri | makan jagung/pakan ayam | meri juga berarti pakannya |
| kebo, sapi | ngembul | memakan rumput | |
| wedhus, kambing | ngrembeh | memakan daun-daunan/rumput | |
| asu | nggreteg | menggerek — makan tulang menggerogoti | |
| manuk | nyuthuk | mematuk makanan kecil-kecil | |
| manuk, baya | ngethog | mematuk — mematuk besar sekali | |
| ayam | mrabu | makan ing tineh — memakan kotoran | |

Kata *dhahar* (krama inggil dari *mangan*) dipakai untuk manusia dalam ragam halus, bukan untuk kewan.

> Catatan penyusunan: daftar menunggu pemeriksaan editorial; pasangan kata untuk kucing, iwak, dan kewan lainnya akan ditambah dari sumber cetak.
