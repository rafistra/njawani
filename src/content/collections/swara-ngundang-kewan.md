## Konteks

Berbeda dengan [[swara-kewan]] yang bunyinya meniru suara kewan itu sendiri, *swara ngundang* adalah bunyi yang dibuat manusia untuk mengundang kewan mendekat — biasanya sambil membawa pakan. Kedua jenis bunyi ini tidak boleh tertukar: kucing dipanggil *pus-pus*, bukan *meong*.

| --- | --- | --- |
| kucing | pus, pus, pus | |
| pitik | kur, kur, kur | |
| asu | jih, jih, jih | |
| kebo | oek, oek, oek | |
| sapi | meh, meh, meh | |
| wedhus | mi, mi, mi | |
