## Konteks

*Ulese* (juga *rupane*) berarti bentuk atau rupa. Kata-kata pada daftar ini menyebut ciri bentuk kewan — sering muncul ketika orang menelaah hewan ternak atau memilih bahan cerita.

| Jawa | Indonesia | Catatan |
| --- | --- | --- |
| belang | belang — bercorak garis | |
| cendheng | berbintik kecil-kecil | |
| buntet | buntung — berekor terpotong | |
| kucir | berkucir — ekor pendek terpotong | |
| piyek | kete — kurus dan kaku | |
| mbengkok | bengkok | |
| wangkang | bengkok tulang — melengkung | |
