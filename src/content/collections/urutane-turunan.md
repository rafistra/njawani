## Konteks

Bahasa Jawa menamai setiap tingkat keturunan dengan kata yang berbeda — bukan sekadar "cucu dari cucu". Urutannya turun dari *anak* sampai jauh ke bawah, dan sebagian kata juga dipakai untuk arah sebaliknya: *buyut* bisa berarti kakek dari kakek.

| Jawa | Indonesia | Catatan |
| --- | --- | --- |
| anak | anak | tingkat pertama |
| putu | cucu | |
| buyut | cicit — anak dari cucu | |
| canggah | anak dari buyut | |
| wareng | anak dari canggah | |
| udheg-udheg | anak dari wareng | |
| gantung siwuruh | generasi berikutnya lagi | |

Ke arah atas dipakai pula: *bapak/ibu* → *mbah* (kakek/nenek) → *buyut*. Untuk garis keturunan bangsawan dipakai istilah *sentana* — keturunan, terutama keturunan raja atau priyayi.

> Catatan penyusunan: urutan di atas adalah urutan yang lazim diajarkan; penamaan tingkat terjauh bervariasi antarwilayah dan menunggu pemeriksaan editorial.
