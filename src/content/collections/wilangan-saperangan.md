## Konteks

Tidak semua benda cukup dihitung dengan "siji, loro". Bahasa Jawa punya *wilangan saperangan*: kata bilangan yang berpasangan dengan bendanya — sirih dihitung *samunting*, daun dihitung *sapapah*. Menjumlahkannya salah justru terasa janggal, seperti menghitung kain dengan "satu butir".

| Benda | Wilangan | Indonesia | Catatan |
| --- | --- | --- | --- |
| sirih | samunting | satu helai (dua sehelai) sirih | |
| godhong | sapapah | satu helai daun | |
| kembang | saseser | satu ikat bunga | |
| lenga | sagendul | satu botol (gendul) minyak | |
| jae | sarempang | satu ruas jahe | |
| sandhangan | sastel | satu stel — satu set baju | |
| piring | saparengan | satu tumpuk piring | |
| telur | sawungan | satu wungan — empat telur | |

> Catatan penyusunan: daftar disarikan dari rujukan di bawah; satuan lain (tikèl, pethèk, gandhik, seket) akan ditambah setelah nilai angkanya dicek silang terhadap sumber cetak.
